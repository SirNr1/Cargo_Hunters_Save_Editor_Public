# Cargo Hunters Save Editor 🛠️

[English](README.md) · **Русский**

Редактор сохранений для игры **Cargo Hunters** (`offline.save`, Steam App ID `4197990`).
Написан на Python и Tkinter, распространяется как портативное приложение для Windows.

Названия предметов, навыков, торговцев и отправителей писем читаются из файлов самой игры,
поэтому вы работаете с понятными названиями, а не с идентификаторами GUID.

## ✨ Возможности

* **🎒 Инвентарь и снаряжение**
  * Редактирование предметов в снаряжении персонажа, в убежище и на вкладках склада.
  * Дублирование с учётом стаков и указанием количества копий.
  * Починка предмета вместе со всем, что к нему присоединено.
* **📦 Полный каталог предметов**
  * Вся база предметов из файлов игры: категории, размеры в сетке, вместимость стака.
  * Добавление любого предмета из каталога прямо в инвентарь.
* **🤝 Подмена товара у торговца**
  * Временно поместить предмет из каталога в ассортимент торговца и купить его в игре.
  * Возвращается само при следующем обновлении ассортимента — или сразу, кнопкой **Undo**
    (действует только в текущем сеансе редактора).
* **📬 Почта**
  * Письма с отправителем, наградами и статусом прочтения. Удаление отдельных писем.
* **☢️ Лаборатория Хакермана**
  * Никнейм, уровень, опыт, уровни навыков (0–10), уровни и балансы торговцев.
  * Читы в один клик. Может испортить сохранение — на самой вкладке об этом написано прямо.
* **🛡️ Изменения не пишутся сразу**
  * Всё накапливается в памяти. Файл сохранения не трогается, пока вы не нажмёте
    **Применить изменения**.
  * Перед каждой записью создаётся резервная копия с отметкой времени в папке `backups/`
    рядом с программой.
* **🌍 Три языка**: английский, немецкий и русский.

Состояние предмета показывается рядом с названием: `COND` по игровой шкале 0–4 для снаряжения
и `DUR` как остаток зарядов для расходников — например, `DUR 3.0/5 (60%)` для ремкомплекта.
Максимумы берутся из данных игры для каждого шаблона, а не считаются от произвольного числа.
У предметов, которых игра ещё не касалась, этих полей нет вовсе — тогда не показывается ничего.

## 🚀 Как запустить

Скачайте архив из раздела [Releases](../../releases), распакуйте в любую папку с правом
записи и запустите `CargoHuntersEditor.exe`. Установка не нужна, Python не нужен.

Редактор сам ищет сохранение: текущая папка, все буквы дисков и путь Steam
`userdata/*/4197990/remote/offline.save`. Задать файл вручную можно ключом `--save-path`.

## ⚠️ Windows предупредит при первом запуске

Сборка не подписана сертификатом, поэтому два предупреждения — это нормально, и ни одно из
них не означает, что с файлом что-то не так:

* **SmartScreen** — «Система Windows защитила ваш компьютер».
  Нажмите **Подробнее → Выполнить в любом случае**.
* **Антивирус** — исполняемые файлы, собранные PyInstaller, дают ложные срабатывания
  постоянно: этим упаковщиком пользуются и обычные программы, и вредоносные.

Программа не выходит в сеть. Она записывает только ваше сохранение и резервные копии в папке
`backups/` рядом с собой.

Если не хотите доверять готовому файлу — запустите из исходного кода. Это тот же самый код.

## 🧑‍💻 Запуск из исходного кода

Нужен Python 3.11+ с `tkinter`.

```bash
python CH_Editor/gui_editor.py
python CH_Editor/gui_editor.py --save-path "путь/к/offline.save"
```

`UnityPy` нужен только для кнопки **Refresh Names from Game**, которая заново вычитывает
названия из ресурсов игры. Готовая таблица названий входит в сборку, так что без него
работает всё остальное.

```bash
pip install UnityPy   # только если хотите обновить названия сами
```
